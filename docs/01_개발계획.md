## 목표

**스케일링 전/후 트래픽 결과를 실측값으로 보여주는 모니터링 대시보드**를 추가하고,
그 측정 결과를 발표 증빙으로 남긴다. 상세 작업은 `03_대시보드명세.md`를 따른다.

## 작업 원칙

1. **실측값만 사용한다.** 예시 수치·추정치·샘플 데이터를 실측처럼 표시하지 않는다.
   발표에 쓰는 모든 수치는 `results/`에 저장된 실제 실행 결과로 추적 가능해야 한다.
2. **측정 조건을 함께 기록한다.** PC 사양(CPU/RAM/OS), target_tps, duration, replica 수, 반복 횟수.
3. **가드레일 값은 변경 금지:** MAX_LOOP 10, Locust 상한 50 TPS, replica 최대 8,
   asyncio.timeout(300), confidence 임계값 0.6.
4. **기존 API 응답 필드는 삭제·이름 변경 금지.** 필드 추가만 허용한다.
5. **`schemas.py`, `state.py`의 기존 필드는 변경 금지.**
6. **변경 후 `pytest tests/` 통과**를 확인하고 커밋한다.
7. CLAUDE.md의 Out of Scope는 이번에도 건드리지 않는다.
